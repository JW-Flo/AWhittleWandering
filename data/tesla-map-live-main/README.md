# Tesla Map Live

## Clean Tesla Location Tracking & Visualization

A modern React application for Tesla vehicle tracking and visualization using TypeScript, Vite, and shadcn/ui components.

## Quick Start

```sh
# Clone the repository
git clone <YOUR_GIT_URL>

# Navigate to project
cd tesla-map-live

# Install dependencies
npm install

# Start development server
npm run dev
```

## Technology Stack

- **Vite** - Build tool and dev server
- **TypeScript** - Type safety
- **React** - UI framework  
- **shadcn/ui** - Modern component library
- **Tailwind CSS** - Utility-first styling

## Development

Start the development server:
```sh
npm run dev
```

Build for production:
```sh
npm run build
```

## Architecture

Clean, modern React architecture with:
- TypeScript for type safety
- shadcn/ui for consistent components
- Tailwind for responsive styling
- Modular component structure
